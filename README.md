# Грамота · Hramota

Приватний офлайн-офіс для Android: документи, таблиці, презентації й PDF в одному швидкому застосунку. Українська та англійська. Безкоштовно, без реклами й акаунтів.

> **Статус: розробка.** Ще немає версії для людей. Помилки й побажання: [Issues](../../issues).

## Що вже є

- 📂 **Відкрити будь-який файл** із телефона або з «Відкрити за допомогою» в інших застосунках.
- 🪟 **Кожен файл в окремому вікні:** окрема картка в «Нещодавніх», працює розділений екран.
- 📄 **PDF** — системним рушієм телефона, сторінка за сторінкою.
- 📝 **DOCX, ODT, TXT, Markdown** — спрощений перегляд тексту (точний рендер сторінок у роботі).
- 🔀 **Порівняння двох версій** DOCX, ODT чи TXT: додане зеленим, видалене червоним, «наступна / попередня зміна».

## Що буде

- Точний вигляд документів, як у Word і LibreOffice: шрифти тієї самої ширини, правила верстки Word, автотести рендеру.
- Редагування, коментарі, режим рецензування.
- Таблиці й презентації, старі формати DOC, XLS, PPT.
- Сканер із розпізнаванням тексту й виправленням помилок з урахуванням української.
- Локальний ШІ (Gemma 4), за бажанням: «поясни, що змінилося», короткий зміст, список справ, заповнення шаблонів.
- Шаблони документів, таблиць і презентацій, функції для соцмереж.

## Прозорість

- **Мережа:** дозволу на інтернет немає; збірка зупиняється, якщо він з'являється.
- **Файли:** застосунок бачить лише файли, які ви відкрили самі. Хмарну копію Android вимкнено.
- **Підпис:** релізи підписуються окремим кроком після схвалення; відбиток сертифіката — у [`signing/certificate-sha256.txt`](signing/certificate-sha256.txt).
