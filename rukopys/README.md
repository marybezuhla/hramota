# Рукопис — відкрита модель розпізнавання українського письма

Модель, яка перетворює написане від руки (стилусом чи пальцем) на текст, просто на телефоні,
без інтернету. Робиться для Грамоти, але задумана як окремий відкритий проєкт, який може взяти будь-хто.

## Принципи

- **Загальна модель не вчиться на чиємусь особистому письмі.** Її джерела — відкриті набори
  рукописів із вільними ліцензіями, штучні зразки (див. нижче) і, згодом, зразки волонтерів, які
  самі вирішили ними поділитися під CC BY 4.0.
- **Підлаштування під людину — лише на її телефоні.** У Грамоті є «Мій почерк» (Налаштування →
  Рукопис): людина пише речення, розпізнавання звикає до її руки. Зразки нікуди не надсилаються,
  під замком сховища шифруються; поділитися ними можна лише самостійно, файлом.
- **Усе відкрите:** код навчання, готова модель і власні дані.

## Як буде влаштовано

| Частина | Що це |
|---|---|
| `data/` | Опис джерел: звідки, ліцензія, контрольні суми. Самі великі набори в git не зберігаються — скрипт завантажує їх. |
| `synth/` | Штучні зразки: текст «пишеться» за траєкторіями відкритих рукописних шрифтів (OFL) і спотворюється — нахил, розмір, швидкість, тремтіння, з'єднання літер. |
| `train/` | Навчання маленької моделі для «живого» письма (послідовність точок → літери, CTC), кілька МБ, експорт в ONNX. |
| `eval/` | Перевірка на відкладених зразках: частка помилок у літерах і словах. |

Розпізнавання в Грамоті:

1. **Р1 (з Грамоти 0.14):** написане малюється в картинку й читається тим самим розпізнаванням, що й сканер
   (PP-OCRv5). Найкраще працює з друкованими літерами.
2. **Р2 (ця модель):** читає саме рух руки, тому справляється і з прописом. Пропозиції звіряються зі
   словником (2,8 млн словоформ), щоб вибиралися справжні слова.
3. **Особисте підлаштування:** нахил, розмір і форми літер людини з «Мого почерку» допомагають
   вибрати правильний варіант серед пропозицій моделі.

Р2 потрапить у Грамоту лише тоді, коли на відкладених зразках розпізнаватиме краще за Р1.

## Формат зразка

Один зразок — один рядок JSON (файл `.jsonl`, так само зберігає «Мій почерк»):

```json
{"text": "Їжак несе листя.", "w": 360, "h": 480, "tool": "stylus",
 "strokes": [[[12.5, 40.1, 0, 0.42], [13.0, 41.7, 8, 0.47]], [[30.2, 38.0, 412, 0.5]]]}
```

Кожен штрих — список точок `[x, y, t, p]`: координати в dp від верхнього лівого кута, час у мс від першої
точки зразка, тиск 0…1 (для пальця завжди 0,5).
