# Рукопис — відкрита модель розпізнавання українського письма

Модель, яка перетворює написане від руки (стилусом чи пальцем) на текст, просто на телефоні,
без інтернету. Робиться для Грамоти, але задумана як окремий відкритий проєкт, який може взяти будь-хто.

## Принципи

- **Загальна модель не вчиться на чиємусь особистому письмі.** Її джерела — відкриті набори
  рукописів із вільними ліцензіями, штучні зразки (див. нижче) і, згодом, зразки волонтерів, які
  самі вирішили ними поділитися під CC BY 4.0.
- **Підлаштування під людину — лише на її телефоні.** У Грамоті є «Мій почерк» (Налаштування →
  Рукопис): людина пише речення, розпізнавання звикає до її руки. Зразки нікуди не надсилаються,
  під замком сховища шифруються; поділитися ними можна лише самостійно, файлом.
- **Усе відкрите:** код навчання, готова модель і власні дані.

## Як влаштовано

| Частина | Що це |
|---|---|
| `synth/fonts.py` | Завантажує рукописні шрифти Google Fonts під SIL Open Font License, у яких є всі українські літери (Caveat, Bad Script, Marck Script, Neucha, Pangolin та інші), і записує для кожного джерело, ліцензію й контрольну суму. |
| `synth/corpus.py` | Рядки для письма: речення з `practice_uk.txt` і рядки зі слів словника наголосів, який уже є в Грамоті (2,9 млн словоформ, ukrainian-word-stress, MIT), — з великими літерами, числами й розділовими знаками. |
| `synth/ink.py` | Штучне письмо: рядок малюється шрифтом, стоншується до ліній в один піксель і трасується назад у штрихи пера; потім нахил, поворот, ширина, хвиляста лінія, тремтіння. |
| `train/features.py` | Що читає модель: рухи пера (dx, dy, «перо опущено»), розмір письма вирівняно. Ті самі кроки в Грамоті — `ink/Rukopys.kt` (тест `RukopysTest` звіряє їх). |
| `train/model.py`, `train/train.py` | Модель (згортки + двобічна GRU, CTC, близько мільйона ваг) і навчання; найкраща за відкладеними шрифтами експортується в ONNX. |
| `eval/compare.py` | Р1 проти Р2 на рядках, написаних шрифтами, яких модель не бачила: частка неправильних літер і слів. Р1 читається так само, як у Грамоті. |

Навчання йде в GitHub Actions (`.github/workflows/rukopys.yml`): пуш у гілку `rukopys-smoke` перевіряє весь шлях за кілька хвилин, у `rukopys-train` — навчає по-справжньому (≈4,5 год). Модель, звіт і список шрифтів потрапляють у гілку `rukopys-model`.

**Чесно про межі.** Штучне письмо — не справжній рух руки: штрихи йдуть за формою літер, а не за тим, як людина веде перо. Тому перевірка на відкладених шрифтах показує лише, чи модель узагалі вчиться. Справжню перевірку робить кожен телефон окремо: «Мій почерк» → «Підлаштувати розпізнавання» читає зразки людини обома способами (і з випрямленим нахилом) і бере той, що помиляється менше. Зразки при цьому нікуди не йдуть.

Розпізнавання в Грамоті:

1. **Р1 (з Грамоти 0.14):** написане малюється в картинку й читається тим самим розпізнаванням, що й сканер (PP-OCRv5). Найкраще працює з друкованими літерами.
2. **Р2 (ця модель):** читає саме рух руки. Входить у Грамоту, коли на відкладених шрифтах читає краще за Р1.
3. **Особисте підлаштування:** на телефоні людини вибирається Р1 чи Р2 і чи випрямляти нахил — за тим, що краще читає її власні зразки.

## Формат зразка

Один зразок — один рядок JSON (файл `.jsonl`, так само зберігає «Мій почерк»):

```json
{"text": "Їжак несе листя.", "w": 360, "h": 480, "tool": "stylus",
 "strokes": [[[12.5, 40.1, 0, 0.42], [13.0, 41.7, 8, 0.47]], [[30.2, 38.0, 412, 0.5]]]}
```

Кожен штрих — список точок `[x, y, t, p]`: координати в dp від верхнього лівого кута, час у мс від першої
точки зразка, тиск 0…1 (для пальця завжди 0,5).
